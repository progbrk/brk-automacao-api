# brk-automacao-api

Backend da **BRK Automação** — API que vai expor dados dos equipamentos (KC868, sensores de
pressão/vazão/nível/corrente) e o cadastro de negócio (clientes, vendas, assinaturas etc, banco
`brk_automacao` — ver repositório [`brk-automacao`](https://github.com/progbrk/brk-automacao)).

Ainda vazio — arquitetura planejada (a definir/scaffoldar): .NET, Clean Architecture (camadas
Core / Application / Infrastructure / API, um projeto por camada), inspirada na estrutura do
`rti-performance-api` (referência de padrão, não código copiado).

Roda numa máquina fixa (a definir qual) pra ficar acessível continuamente.
